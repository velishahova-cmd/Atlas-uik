# Атлас УИК Москвы

Интерактивная карта Москвы по 1 442 бумажным УИК с результатами (Госдума 2026, федеральный список). Ещё один УИК, № 9003, есть в исходной базе без данных протокола и исключён из показателей и карты. Три слоя карты:

- **Районы** и **Округа**: заливка по выбранному показателю (доля КПРФ, КПРФ против среднего по группе, первое место, отрыв от ЕР, явка, ЕР, ЛДПР, аномалии).
- **Участки**: каждая точка стоит на помещении для голосования, цвет показывает партию на первом месте по бумажным бюллетеням этого УИК. Красная: КПРФ, серая: Единая Россия, синяя: другая партия, половинки: ничья. Бледная точка: отрыв первой партии меньше 5 п.п. Кольцо: статистическая аномалия по другой партии. Пунктир: место приблизительное. Фильтры «КПРФ первая», «На грани» и «Вместе» (обе группы точек сразу); поиск по номеру УИК приближает карту к точке.

Также: региональные группы КПРФ № 33 и № 34, рейтинг районов, явка против доли ЕР, распределение голосов КПРФ, бумага против ДЭГ.

## Состав

| Файл | Что это |
|---|---|
| `index.html` | Всё приложение: разметка, стили, логика (d3 v7 с cdnjs). Без сборки. |
| `data.js` | Данные: участки с координатами, ДЭГ, аномалии, геометрия районов и округов. Генерируется скриптом. |
| `build_data.py` | Пересобирает `data.js` из таблицы xlsx, GeoJSON районов, `new17.csv` и `uik_coords.csv`. |
| `new17.csv` | 17 участков, появившихся в источнике после снимка таблицы. |
| `uik_coords.csv` | Адреса и координаты помещений УИК. |

## Запуск локально

Открыть `index.html` в браузере. Нужен интернет для загрузки d3 с cdnjs и шрифтов с Google Fonts.

## Адрес

https://velishahova-cmd.github.io/Atlas-uik/

Страница публикуется через GitHub Pages из ветки `main`, папка `/ (root)`. Чтобы обновить атлас, достаточно заменить `index.html` и `data.js` в репозитории: через минуту по тому же адресу будет новая версия.

## Пересборка данных

```bash
pip install openpyxl "shapely>=2.1"
python build_data.py таблица.xlsx Москва_Moscow.geojson data.js new17.csv uik_coords.csv
```

Таблица: листы «РГ 33 КПРФ» и «РГ 34 КПРФ» в текущей структуре (шапка на пятой строке, строки УИК и ДЭГ, ниже раздел «Статистические аномалии»). GeoJSON районов: `Москва_Moscow.geojson` из репозитория timurkanaz/Russia_geojson_OSM (OpenStreetMap, ODbL). Без `uik_coords.csv` слой «Участки» будет пустым, без `new17.csv` соберутся 1 426 участков из таблицы.

Формат `uik_coords.csv`: `номер;широта;долгота;источник;населённый пункт;улица;дом;учреждение`. Источник: `m` Мосгоризбирком (здание), `o` OpenStreetMap (здание), `r` улица, `p` посёлок или микрорайон, `d` адреса нет.

## Как получены координаты и как проверены

- 1 235 участков: координаты здания из сервиса поиска УИК Мосгоризбиркома (снимок 15.10.2026).
- 182 участка: у сервиса нет координат, адрес найден в OpenStreetMap через Nominatim. Каждая такая точка проверена обратным геокодированием: номер дома совпал в 142 из 159 уникальных адресов, остальные расхождения разобраны вручную.
- 24 точки стоят приблизительно: 10 по улице, 14 по посёлку или микрорайону. УИК 9002 в открытых данных без адреса, его точка в центре района. На карте эти 25 точек обведены пунктиром. УИК 9003 также без адреса, но до появления протокола на карте не показывается.
- Все точки проверены попаданием в полигон своего района. Вне полигона 24 точки, все на границах Новой Москвы: полигоны OpenStreetMap старше реформы 2024 года. Найденные ошибки исправлены, среди них 2 точки самого сервиса Мосгоризбиркома (УИК 943 и 2170).
- Независимая проверка пересчитала победителей из исходной таблицы: КПРФ первая на 290 участках, ЕР на 1 021, другие партии на 121, ничьих 10 (все с участием КПРФ). Пустая строка УИК 9003 не участвует в средних, долях и количестве участков с результатами.

## Ограничения

- Семь районов Новой Москвы 2024 года (Коммунарка, Филимонковский, Щербинка; Троицк, Краснопахорский, Вороново, Бекасово) показаны двумя контурами административных округов: отдельных границ в открытых данных пока нет.
- Контуры одномандатных округов получены объединением районов по привязке участков из протоколов. Проверено: все участки каждого из 132 районов относятся к одному округу, поэтому ни один район не разрезан. Из 1 441 точки с настоящим адресом 1 437 лежат внутри контура своего округа, ещё 4 стоят в 330–360 м за границей (помещение УИК находится в соседнем районе).
- Контуры районов упрощены одним проходом для всего города (`shapely.coverage_simplify`): соседние районы делят общую границу без щелей и наложений, линии округов лежат точно на границах районов. Отклонение от OpenStreetMap: в среднем 11 м, максимум 45 м.
- Полигоны OpenStreetMap для Новой Москвы старше реформы 2024 года: район Внуково нарисован в старых границах, поэтому его посёлки (Кокошкино, Марушкино, Крёкшино) попадают в контур Новомосковского округа. На контур одномандатного округа № 201 это не влияет: оба контура входят в него.
- Точка показывает помещение для голосования, а не территорию участка: границ участков в открытых данных нет.
- Цвет точки считается только по бумажным бюллетеням, ДЭГ в разрезе участков не публикуется.
